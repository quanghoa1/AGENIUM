# Agenium brand

The mark is an "A" of two rails from the Lead node (top) to the workers (feet), crossed by a ticket and closed by the
merge-queue arc.

| File | Used for |
|---|---|
| `agenium-logo-banner-dark.svg` | the README banner |
| `agenium-logo-mark.svg` | the full mark |
| `agenium-logo-symbol.svg` | the symbol without its tile |
| `apps/desktop/ui/public/logo.svg` | the app's favicon and the source of the app icons |
| `apps/desktop/ui/src/components/Logo.tsx` | the mark at 32–40 px (sidebar, first-start setup), strokes thickened to read small |
| `apps/desktop/icons/` | window, taskbar and bundle icons (`tauri.conf.json` → `bundle.icon`), generated from `logo.svg` with the Tauri CLI (`tauri icon apps/desktop/ui/public/logo.svg`) |
